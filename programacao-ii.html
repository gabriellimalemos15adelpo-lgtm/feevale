Criando um projeto Java

O workspace é a pasta de trabalho do Eclipse. Dentro dela, você organiza os projetos da disciplina.

Sequência apresentada na aula:

  1. Criar uma pasta para o workspace, como wsFeevale.
  2. Abrir o Eclipse e selecionar essa pasta.
  3. Acessar File > New > Project > Java Project.
  4. Dar um nome ao projeto e selecionar o ambiente JavaSE-1.8, conforme o material.
  5. Criar as classes Java dentro do projeto.

JavaSE-1.8 corresponde ao Java 8, versão de referência das apresentações. A aula trabalha inicialmente com projetos Java desktop; projetos Web aparecem mais adiante na disciplina.

02

Introdução ao Java Swing

Uma GUI é uma interface gráfica: janelas, botões, campos e outros controles permitem que o usuário interaja com o programa. Esses controles também são chamados de componentes ou widgets.

O Swing é a biblioteca usada nas aulas para criar essas interfaces. Ele se apoia no AWT e integra o conjunto JFC, que também abrange acessibilidade, gráficos 2D e recursos de arrastar e soltar.

JFrame: a janela principal

JFrame é uma janela de nível superior e pode conter outros componentes. JPanel é um painel usado para agrupar componentes dentro da interface.

OperaçãoFinalidade
new JFrame("Título")Criar uma janela com título
setSize(500, 200)Definir largura e altura da janela
add(componente)Adicionar um componente ao conteúdo da janela
setLayout(...)Escolher como os componentes serão organizados
setDefaultCloseOperation(...)Definir o comportamento ao fechar
setVisible(true)Mostrar a janela

O material também cria classes que herdam de JFrame. Nesse caso, super("Título") chama o construtor da superclasse, e o construtor da nova classe reúne as configurações da janela.

O que acontece ao fechar?

ConstanteComportamento
EXIT_ON_CLOSESolicita o encerramento da aplicação por System.exit
DISPOSE_ON_CLOSEFecha a janela e libera seus recursos de exibição; outras janelas ou tarefas podem continuar
HIDE_ON_CLOSEEsconde a janela, permitindo mostrá-la novamente
DO_NOTHING_ON_CLOSENão executa automaticamente uma ação de fechamento
Ponto de atenção

Ajuste em relação ao slide: a diferença entre EXIT_ON_CLOSE e DISPOSE_ON_CLOSE é o encerramento da aplicação versus o descarte da janela. DISPOSE_ON_CLOSE não garante o encerramento de todo o programa. Referência: JFrame (abre em outra aba).

As cinco partes do JFC mencionadas na aula

  • AWT: componentes, infraestrutura de janelas e eventos.
  • Swing: componentes de interface usados nas aplicações do roteiro.
  • Accessibility: suporte a recursos de acessibilidade.
  • Java 2D: desenho, formas, fontes e cores.
  • Drag and Drop: transferência de dados ao arrastar e soltar.
03

Layouts Java Swing

Um gerenciador de layout determina a posição e o tamanho dos componentes. Isso permite que a interface se reorganize quando a janela muda de tamanho.

LayoutComo organizaExemplo de uso
FlowLayoutColoca componentes em sequência e quebra a linha quando falta espaçoFileira de botões
BorderLayoutDivide o espaço em NORTH, SOUTH, EAST, WEST e CENTERBarra no topo e conteúdo no centro
GridLayoutDistribui componentes em uma grade de células do mesmo tamanhoTeclado de calculadora
nullDeixa o posicionamento manual com setBoundsExemplos com coordenadas fixas
CardLayoutAlterna qual painel fica visívelDiferentes telas na mesma região
BoxLayoutOrganiza componentes em uma linha ou colunaFormulário vertical
GridBagLayoutUsa uma grade flexível, com tamanhos e ocupações diferentesFormulário mais elaborado
SpringLayoutPosiciona usando relações e restrições entre componentesDistâncias entre bordas

Exemplos de trechos usados na configuração de uma janela:

setLayout(new FlowLayout());
add(new JButton("Salvar"));
add(new JButton("Cancelar"));
setLayout(new BorderLayout());
add(new JButton("Topo"), BorderLayout.NORTH);
add(new JTextArea(), BorderLayout.CENTER);
setLayout(new GridLayout(2, 3));

O padrão de JPanel é FlowLayout; o painel de conteúdo de JFrame usa BorderLayout. Em uma região de BorderLayout, use um painel para reunir vários componentes.

Layout nulo e setBounds

setLayout(null);
campo.setBounds(10, 20, 180, 30);

A ordem é x, y, largura, altura. Nesse exemplo, o campo começa a 10 pixels da esquerda e 20 do topo de seu contêiner, com 180 de largura e 30 de altura. O posicionamento fixo exige mais cuidado ao redimensionar a janela.

JLabel, JButton e JTextField

ComponenteFunçãoMétodos úteis
JLabelExibir um rótulo ou texto informativosetText, getText
JTextFieldReceber texto em uma linhagetText, setText
JButtonPermitir que o usuário dispare uma açãoaddActionListener, setActionCommand

O ciclo básico é criar o componente, configurá-lo e adicioná-lo ao contêiner.

JLabel rotulo = new JLabel("Nome:");
JTextField campo = new JTextField(20);
JButton apagar = new JButton("Apagar");

apagar.addActionListener(evento -> campo.setText(""));

O 20 de JTextField(20) indica colunas usadas no cálculo da largura preferida. Ele não limita a entrada a 20 caracteres.

O botão precisa de um listener para executar o comportamento desejado. setActionCommand("Apague") atribui um identificador ao evento, que pode ser consultado com getActionCommand(). O comando, sozinho, não implementa a ação.

05

Conhecendo o JOptionPane

JOptionPane fornece caixas de diálogo prontas. Nos usos apresentados, os diálogos são modais: enquanto estão abertos, bloqueiam a interação com a janela à qual se aplicam.

MétodoUso
showMessageDialogMostrar uma mensagem
showInputDialogSolicitar uma entrada
showConfirmDialogPedir confirmação e retornar a opção escolhida
showOptionDialogConfigurar opções e botões com maior flexibilidade
JOptionPane.showMessageDialog(
    null, "Cadastro salvo!", "Aviso", JOptionPane.INFORMATION_MESSAGE
);

O primeiro argumento indica o componente de referência. Com null, não se informa um componente pai; com a própria janela, o diálogo se relaciona a ela. Há variantes do método com título, tipo de mensagem e ícone personalizado: isso exemplifica sobrecarga.

Tipos de mensagem: PLAIN_MESSAGE, INFORMATION_MESSAGE, WARNING_MESSAGE, QUESTION_MESSAGE e ERROR_MESSAGE.

Entrada e conversão

Na forma textual usada na aula, showInputDialog retorna uma String, ou null se houver cancelamento. Para calcular com o valor, é necessário convertê-lo.

String entrada = JOptionPane.showInputDialog(null, "Informe sua idade:");

if (entrada != null) {
    try {
        int idade = Integer.parseInt(entrada);
        JOptionPane.showMessageDialog(null, "Próxima idade: " + (idade + 1));
    } catch (NumberFormatException erro) {
        JOptionPane.showMessageDialog(null, "Digite um número inteiro válido.");
    }
}

A verificação de cancelamento e o tratamento de entrada inválida foram acrescentados ao exemplo para evitar falhas.

Confirmação

int resposta = JOptionPane.showConfirmDialog(
    null, "Deseja continuar?", "Confirmação", JOptionPane.YES_NO_OPTION
);

if (resposta == JOptionPane.YES_OPTION) {
    // Executar a ação confirmada.
}
Ponto de atenção

Não confundir: YES_NO_OPTION e YES_NO_CANCEL_OPTION configuram os botões disponíveis. YES_OPTION, NO_OPTION, CANCEL_OPTION e CLOSED_OPTION são resultados possíveis da interação. Essa distinção está misturada na lista de constantes do slide. Referência: JOptionPane (abre em outra aba).

Entendendo os listeners

Um evento descreve uma interação, como clicar ou digitar. Um listener é um objeto registrado para receber eventos e executar um método em resposta.

Fluxo: usuário interage → componente gera evento → listener recebe o evento → método executa uma ação.

ListenerMétodos principaisO que observa
ActionListeneractionPerformedAções, como ativar um botão
KeyListenerkeyPressed, keyReleased, keyTypedTeclado
MouseListenermouseClicked, mouseEntered, mouseExited, mousePressed, mouseReleasedCliques, entrada e saída do mouse
ItemListeneritemStateChangedMudanças de seleção
ListSelectionListenervalueChangedMudanças de seleção em listas

As apresentações mostram diferentes formas de criar um listener: a própria classe implementa a interface, uma classe interna implementa a interface ou uma classe anônima é criada no registro do listener. Para ActionListener, também é possível usar uma lambda, como nos exemplos reduzidos deste resumo.

Ponto de atenção

Ajuste conceitual: os listeners AWT listados não herdam todos de WindowListener; essas interfaces se baseiam em java.util.EventListener. WindowListener é específico para eventos de janela. Referência: WindowListener (abre em outra aba).

mouseReleased e mouseClicked podem coexistir. No exemplo da aula, ambos alteram a cor do campo em sequência; por isso, uma alteração pode substituir visualmente a outra. Caixas modais dentro dos eventos de teclado também podem mudar o foco e dificultar a observação da sequência de eventos.

Outros listeners apresentados

ListenerEvento observado
AdjustmentListenerAjuste de um valor, como em uma barra de rolagem
ComponentListenerMudanças de tamanho, posição ou visibilidade de um componente
ContainerListenerAdição ou remoção de componentes em um contêiner
FocusListenerGanho ou perda de foco
TextListenerMudança de texto em componentes AWT que oferecem esse evento
WindowListenerAbertura, fechamento e outras mudanças de estado de janela

Movimento do mouse e rolagem têm listeners próprios: MouseMotionListener e MouseWheelListener. O roteiro os menciona, mas não desenvolve exemplos completos.

Mais sobre entrada de texto

Estados do campo

ConfiguraçãoResultado
setVisible(false)O componente deixa de aparecer
setEnabled(false)O componente fica desabilitado
setEditable(false)O texto não pode ser alterado pelo usuário; o campo pode continuar habilitado

JPasswordField

É um campo de senha que herda de JTextField e oculta os caracteres na exibição. O símbolo mostrado depende da aparência configurada. Para obter a senha, usa-se getPassword(), que retorna um vetor de caracteres.

JTextArea

Permite texto em várias linhas. getText() obtém o conteúdo, setText() substitui e append() acrescenta texto.

JTextArea area = new JTextArea(5, 30);
area.setText("Primeira linha");
area.append("\nSegunda linha");

Nesse construtor, os argumentos representam linhas e colunas, usados no tamanho preferido. Para rolagem, coloque a área em um JScrollPane.

Bordas

BorderFactory cria bordas, aplicadas por setBorder():

area.setBorder(BorderFactory.createCompoundBorder(
    BorderFactory.createTitledBorder("Observações"),
    BorderFactory.createEtchedBorder()
));

createTitledBorder cria uma borda com título; createEtchedBorder cria um efeito de relevo; createCompoundBorder combina duas bordas.

08

Mais componentes: seleção

ComponenteQuando usar
JCheckBoxOpções independentes, que podem estar marcadas simultaneamente
JRadioButton + ButtonGroupOpções mutuamente exclusivas
JComboBoxEscolha em uma lista suspensa, ocupando menos espaço

O ButtonGroup gerencia a exclusividade, mas não desenha os botões. Cada JRadioButton deve ser adicionado também ao painel ou à janela. Um grupo pode começar sem seleção; depois de selecionar uma opção, a seleção de outra substitui a anterior.

JRadioButton arial = new JRadioButton("Arial", true);
JRadioButton verdana = new JRadioButton("Verdana");

ButtonGroup grupo = new ButtonGroup();
grupo.add(arial);
grupo.add(verdana);

Métodos frequentes: isSelected() consulta um checkbox ou radio button; getSelectedItem() obtém a escolha de um combo; getSelectedIndex() retorna sua posição.

ItemListener recebe mudanças de seleção e pode receber eventos de desmarcação e marcação. Quando a ação deve ocorrer apenas ao selecionar, verifique evento.getStateChange() == ItemEvent.SELECTED, como faz o exemplo de JComboBox da aula.

09

JList e JMenuBar

JList

Exibe itens em uma lista. JScrollPane fornece rolagem quando necessário. setVisibleRowCount participa do cálculo da altura preferida; não limita a quantidade total de itens.

Modo de seleçãoPermite
SINGLE_SELECTIONUm item
SINGLE_INTERVAL_SELECTIONUm intervalo contínuo de itens
MULTIPLE_INTERVAL_SELECTIONItens ou intervalos separados

Use getSelectedValue() para obter um item e getSelectedValuesList() para obter os selecionados. Sem seleção, getSelectedIndex() retorna -1; verifique isso antes de usar o índice em um vetor.

JMenuBar

A estrutura é JMenuBar → JMenu → JMenuItem: barra, menu e opção acionável.

JMenuBar barra = new JMenuBar();
JMenu arquivo = new JMenu("Arquivo");
JMenuItem sair = new JMenuItem("Sair");

sair.addActionListener(evento -> dispose());
arquivo.add(sair);
barra.add(arquivo);
setJMenuBar(barra);

Esse trecho fica dentro de uma classe que herda de JFrame. As opções usam ActionListener, assim como os botões. No material, os menus alteram a cor e a fonte de um campo de texto.

+

Exemplo integrado: campo e botão

Exemplo didático completo que reúne janela, layout, rótulo, campo, botão, listener e diálogo. Salve como ExemploSwing.java.

import java.awt.FlowLayout;
import javax.swing.*;

public class ExemploSwing extends JFrame {
    private final JTextField nome = new JTextField(20);

    public ExemploSwing() {
        super("Exemplo de cadastro");
        setLayout(new FlowLayout());

        add(new JLabel("Nome:"));
        add(nome);

        JButton mostrar = new JButton("Mostrar");
        mostrar.addActionListener(evento -> {
            JOptionPane.showMessageDialog(
                this, "Nome informado: " + nome.getText()
            );
        });
        add(mostrar);

        setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        pack();
        setLocationRelativeTo(null);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new ExemploSwing().setVisible(true);
        });
    }
}

pack() dimensiona a janela pelos tamanhos preferidos dos componentes. SwingUtilities.invokeLater agenda a criação da interface na thread de eventos do Swing; é um complemento de boa prática aos exemplos das apresentações.

  • Janela: JFrame; painel: JPanel.
  • Exibir texto: JLabel; receber uma linha: JTextField; várias linhas: JTextArea.

  • Mostrar mensagem ou pedir dados: JOptionPane.
  • Posicionar automaticamente: gerenciador de layout; manualmente: null e setBounds.
  • Escolhas independentes: JCheckBox; exclusivas: JRadioButton com ButtonGroup.
  • Lista suspensa: JComboBox; lista visível: JList.
  • Menus: JMenuBar, JMenu e JMenuItem.

01

Classes, objetos, atributos e métodos

Uma classe define uma estrutura e seus comportamentos. Um objeto é uma instância dessa classe.

ConceitoSignificadoExemplo
ClasseEspecificação dos objetosAluno
ObjetoUma instância concretaUm aluno criado com new Aluno()
AtributoDado que compõe o estadoNome, matrícula
MétodoOperação ou comportamentoAlterar nome, calcular média

O material caracteriza um objeto por identidade, estado e comportamento. Objetos diferentes podem ter o mesmo estado: dois alunos podem ter o mesmo nome sem serem o mesmo objeto.

class Aluno {
    private String nome;

    public void setNome(String nome) {
        this.nome = nome;
    }

    public String getNome() {
        return nome;
    }
}

this.nome identifica o atributo do objeto atual; nome, à direita da atribuição, é o parâmetro recebido pelo método.

02

Métodos de classe e métodos de objeto

TipoCaracterísticaChamada do material
De classe (static)Pode ser chamado sem criar uma instância da classeMath.sqrt(4)
De instânciaÉ chamado sobre um objetoa.intValue()

Os membros static pertencem à classe. Atributos de instância compõem o estado de cada objeto. Um método estático não tem this e não acessa diretamente atributos de instância sem uma referência a um objeto.

03

Encapsulamento

Encapsular é reunir estado e comportamento e controlar como outras partes do programa acessam esse estado.

No exemplo da aula, valor é private; o acesso externo acontece por getValor() e setValor(). Isso permite concentrar regras de alteração em um lugar.

class Encapsulamento {
    private double valor;

    public double getValor() {
        return valor;
    }

    public void setValor(double valor) {
        if (valor > 10) {
            throw new IllegalArgumentException("O valor deve ser no máximo 10.");
        }
        this.valor = valor;
    }
}

A validação acima adapta a regra sugerida pelo professor no vídeo; o arquivo fornecido apenas atribui o valor. O ponto central é controlar a alteração. Getters e setters são recursos possíveis; não é obrigatório oferecer um setter para todo atributo.

04

Associação, agregação e composição

São formas de representar relações entre objetos. Agregação e composição são relações de todo e parte.

RelaçãoIdeia centralExemplo da aulaRepresentação UML
AssociaçãoObjetos se relacionam ou um utiliza o outroAutomóvel utiliza uma rodoviaLinha; seta pode indicar navegabilidade
AgregaçãoUma parte tem existência independente do todoAutomóvel e buzinaLosango vazio no lado do todo
ComposiçãoA parte pertence ao todo e seu ciclo de vida depende dele no modeloLivro e seus capítulos cadastradosLosango preenchido no lado do todo

No exemplo de composição, excluir o livro implica excluir seus capítulos daquele cadastro. Na agregação, a buzina pode continuar existindo separadamente.

Essas relações descrevem o modelo do sistema. Declarar um atributo Java, sozinho, não implementa automaticamente todas as regras de ciclo de vida da composição.

05

Herança

Permite definir uma classe a partir de outra. A classe original é a superclasse ou classe base; a que herda é a subclasse ou classe derivada. A palavra-chave é extends.

Exemplo reduzido dos arquivos da aula:

class ClasseBase {
    public static int soma(int x, int y) {
        return x + y;
    }
}

class ClasseDerivada extends ClasseBase {
    public static int produto(int x, int y) {
        return x * y;
    }
}
int soma = ClasseDerivada.soma(5, 6);       // 11
int produto = ClasseDerivada.produto(5, 6); // 30

soma vem da classe base; produto foi definido na derivada. Como ambos são estáticos nesse exemplo, não é preciso instanciar um objeto.

Java permite que uma classe tenha uma única superclasse direta. Uma classe pode implementar várias interfaces.

Na UML, a herança é representada por uma linha com triângulo vazio apontando para a superclasse.

06

Sobrecarga de métodos - overloading

Ocorre quando há métodos com o mesmo nome e listas de parâmetros diferentes. Pode mudar a quantidade, os tipos ou a ordem dos tipos dos parâmetros.

class SobrecarregandoMetodos {
    public int dobra(int x) {
        return 2 * x;
    }

    public double dobra(double x) {
        return 2.0 * x;
    }

    public double dobra(int x, int y) {
        return 2 * (x + y);
    }
}
ChamadaResultadoVersão selecionada
dobra(3)6Um int
dobra(3.5)7.0Um double
dobra(2, 3)10.0Dois int

A escolha da sobrecarga é feita na compilação, considerando os tipos dos argumentos e as regras da linguagem. Mudar somente o tipo de retorno não cria uma sobrecarga válida.

07

Sobrescrita de métodos - overriding

A subclasse fornece uma nova implementação para um método de instância herdado, mantendo uma assinatura compatível.

class ClasseBase2 {
    public void escreveTitulo() {
        System.out.println("Feevale");
    }
}

class ClasseDerivada2 extends ClasseBase2 {
    @Override
    public void escreveTitulo() {
        System.out.println("Universidade Feevale");
    }
}

Uma instância de ClasseDerivada2 executa a implementação da derivada. @Override ajuda o compilador a verificar que o método realmente sobrescreve outro.

Ponto de atenção

Diferença para memorizar: sobrecarga muda os parâmetros; sobrescrita muda o comportamento herdado. Métodos static não são sobrescritos como métodos de instância: uma declaração estática correspondente pode ocultar a anterior.

08

Interfaces

Uma interface define um contrato que pode ser atendido por classes diferentes. O material usa a ideia de um Voador:

interface Voador {
    void levantaVoo();
    void plana();
    void pousa();
}

Uma classe concreta que declara implements Voador deve fornecer ou herdar implementações para esses métodos abstratos. Nos métodos acima, public abstract é implícito. A implementação na classe precisa ser public.

Uma interface não pode ser instanciada diretamente e não tem construtor. É possível usar seu tipo em uma variável que referencia um objeto de uma classe implementadora.

No roteiro 1, isso já aparece em implements ActionListener: a classe atende ao contrato implementando actionPerformed.

Ponto de atenção

Esclarecimento de versão: a afirmação dos slides de que interfaces só têm métodos sem implementação é uma simplificação. No Java 8, interfaces também podem declarar métodos default e static com corpo. Métodos privados em interfaces existem a partir do Java 9; não são aceitos no JavaSE-1.8 indicado pelo roteiro 1. Os campos de interface são constantes public static final, não atributos de instância privados. Referência: interfaces na especificação Java (abre em outra aba).

09

Polimorfismo

Significa trabalhar com um mesmo tipo comum e obter comportamentos diferentes conforme o objeto concreto. O exemplo central da aula usa figuras geométricas.

FiguraÁreaPerímetro
Círculoπ × raio²2 × π × raio
Quadradolado²4 × lado
Triângulobase × altura / 2Soma dos três lados

Todas podem oferecer calculaArea() e calculaPerimetro(), cada uma com sua implementação. Isso pode ser organizado por herança ou por interface.

Exemplo adaptado com interface, mostrando apenas a área:

interface Figura {
    double calculaArea();
}

class Quadrado implements Figura {
    private final double lado;

    Quadrado(double lado) {
        this.lado = lado;
    }

    @Override
    public double calculaArea() {
        return lado * lado;
    }
}

class Circulo implements Figura {
    private final double raio;

    Circulo(double raio) {
        this.raio = raio;
    }

    @Override
    public double calculaArea() {
        return Math.PI * raio * raio;
    }
}
Figura figura = new Quadrado(4);
System.out.println(figura.calculaArea()); // 16.0

figura = new Circulo(2);
System.out.println(figura.calculaArea()); // aproximadamente 12.57

A variável continua sendo do tipo Figura; o método executado depende do objeto. Não é preciso escolher a fórmula com vários if espalhados pelo programa.

Ponto de atenção

Esclarecimento: o polimorfismo por subtipos não exige uma superclasse abstrata. Ela é uma possibilidade; também pode haver uma superclasse concreta ou uma interface.

Outros tipos de polimorfismo citados

TipoComo aparece no material

ParamétricoDefinições genéricas que operam sobre diferentes tipos

O roteiro cita ainda polimorfismo estrutural e de linha, sem desenvolvê-los nas apresentações.

Conversão de tipos

float x = 10.7f;
int y = (int) x; // 10

O cast para int descarta a parte fracionária nesse exemplo; não arredonda para o inteiro mais próximo. Foi acrescentado o sufixo f que falta no slide: 10.7 sem sufixo é um literal double. Referência: literais de ponto flutuante (abre em outra aba).

Método genérico

public static <E> void escreve(E[] vetor) {
    for (E elemento : vetor) {
        System.out.println(elemento);
    }
}

E representa um tipo de referência. O método pode receber, por exemplo, String[] ou Integer[]. Não recebe diretamente int[] nessa forma. Seu retorno é void: ele percorre e imprime os elementos, não retorna um vetor.
